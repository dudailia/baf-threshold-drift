# Reviewing this study in ten minutes

Every departure from the brief or the paper is listed, with reasons and commits, in [reports/deviations.md](reports/deviations.md).

## 1. Pre-registration

PREDICTIONS.md was committed in `0be4b0d` ("Pre-register predictions"), before any model was trained. It holds the user's 12 answers to an interview about expected budget misses, TPR and age-group FPR ratios (Base and Variants I to III, then Variants IV and V separately), plus two additional predictions, each with a stated confidence. The rules used to score them were declared in PROTOCOL.md ("Scoring rules for PREDICTIONS.md") in `290a3c0`, also before the main run.

To confirm that results came after it:

```
git log --format='%h %ad %s' --date=iso -- PREDICTIONS.md   # one commit only: 0be4b0d
git merge-base --is-ancestor 0be4b0d 9c04644 && echo "main results came after the pre-registration"
.venv/bin/python -m src.guard                                # fails if PREDICTIONS.md changed since 0be4b0d
head -c 300 results/metrics.csv                              # every results file carries predictions_commit = 0be4b0d...
```

`make train` and `make evaluate` refuse to run unless PREDICTIONS.md is committed and unchanged.

## 4. Rebuild

Put the six CSV files in `data/raw/` (see README.md), then:

```
make setup                 # venv from the pinned requirements.txt
make test                  # unit and pipeline tests, about a minute
make audit                 # data audit, under a minute
make sample                # 10% sample of Base, full pipeline, a few minutes
make check                 # every number in the documents traces to results/
make clean && time make all   # full rebuild from data/raw/, about an hour
```

A clean `make all` on 2026-10-17 took 3,656 seconds and reproduced every results file exactly (reports/reproducibility.md), and a fresh clone with a new venv passed `make test`, `make audit` and `make sample`.

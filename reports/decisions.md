# Decisions for the post hoc queue

Choices made without asking, during the unattended post hoc queue (PROTOCOL.md, "Post hoc analyses"). Where a choice was ambiguous, the more conservative option was taken.

| Task | Decision | Reason |
|---|---|---|
| all | Main-study code is reused; new parameters default to the main-study values, and no main-study command (`make train`, `make evaluate`, `make values`) is run, so results/ is not rewritten. | A change to any main-study result file is a hard stop. |
| all | Paired bootstrap resamples use the same weight keys as the main study (variant, month, chunk), so post hoc and main strategies are evaluated on the same resampled rows of a month. | Makes post hoc against main comparisons paired, as in the main study. |
| all | Primary settings as in the main study: 5% target, older group `customer_age >= 50`, 1,000 resamples, seed 0 intervals, verdict rule from PROTOCOL.md. | Same intervals as the main study, as asked. |
| 1 | Same 20 configurations (seed 2022) as the main study, tuned on each split's validation month by TPR at 5% FPR; 5 seeds; intervals for seed 0 only, seed spread from all 5. | Same tuning budget and intervals as the main study, as asked. |
| 1 | All strategies are computed, but only static, label-free top 5%, delayed-label lag 1 and the oracle are stored and reported. | Exactly the strategies named in the task. |
| 1 | "Later months" is read as months 5 to 7, the months where the main study found the under-spend; split A's months 3 and 4 are reported too. | Keeps the robustness question identical to the main finding and hides nothing. |
| 2 | LightGBM seed 0 of the main study. The model is refit (same data, configuration and seed) because models were not saved; the refit is checked against the saved scores and the difference is reported. | Predictions alone cannot be rescored with replaced features. |
| 2 | Five independent replacement draws per feature and month, mean and range reported; raw values (including sentinels) are drawn, then preprocessed as in training. One feature is replaced at a time; joint effects are not tested. | Single draws are noisy; joint replacement was not asked for. |
| 3 | Top 5 tuning trials by validation TPR (ties to the earlier trial); rank 1 reuses the main study's saved predictions. Strongly regularised model: 200 trees, depth 3, 8 leaves, at least 2,000 rows per leaf, learning rate 0.05, GBDT. 5 seeds each; seed 0 intervals and a paired comparison against the main model. | Rank 1 is the main model by construction; the regularised setting is far from every tuned configuration. |
| 4 | 5 seeds, each with the main study's configuration for that variant (identical across seeds). The retrained threshold is set on month t-1 with that month's labels, the same information as delayed-label lag 1. | No re-tuning, as asked. |
| 5 | Isotonic regression clipped to [0, 1]; in the bootstrap, month 3 is resampled and the isotonic map refitted in every resample. | Includes calibration uncertainty in the intervals. |
| amend | In RESULTS.md the original sentences are kept verbatim as quotations inside "Amendment 2026-10-17" and the body is reworded; README.md and the one-pager are reworded, with the original text kept in git history (commit 125042c). | Deleting the original wording is a hard stop; quoting it keeps it in the file. |
| amend | Main documents are rendered from results/ and results_posthoc/ (results/ takes precedence), so the amendment's post hoc numbers are traced by the same checker. | Every number in the amendment must be traced. |
| 6 | Seed 0 with 1,000 paired resamples per (m, t) pair, using the main study's resample keys; seeds 0 to 4 for the seed spread. | Same intervals as the main study. |
| 7 | Fixed top-q rules evaluated on the main LightGBM scores, 5 seeds, seed 0 intervals paired with the cached isotonic resamples (same rows); budget miss always against 5%. | Makes the comparison with task 5 paired. |
| clean | `make clean` removes everything `make all` regenerates (results files, checkpoints, predictions, logs, figures, rendered documents, generated reports) but keeps results/independent_check.csv and results_posthoc/. | The independent check and the post hoc results are not produced by `make all`; deleting them could not be undone by the rebuild. |
| 4 | After the clean rebuild, the three files that differed only in metadata or fit times (manifest timestamp, tripwires key order, replication fit_seconds) were restored to their committed versions. | Changing any number in results/ is a hard stop; the differences were recorded in reports/reproducibility.md first. |
| paths | Absolute paths in the four checker scripts replaced by paths relative to the repository root; the post hoc checker's output folder became `checker_output/independent_check_posthoc/` (added to .gitignore). Each script gained a one-line comment saying so. History was not rewritten. | Scripts stay runnable and otherwise verbatim; rewriting history is irreversible and was not asked for. |
| 4 | Data origin quoted from the Kaggle dataset description (read from Kaggle's public API record, `api/v1/datasets/view/sgpjesus/bank-account-fraud-dataset-neurips-2022`, because the web page itself is a JavaScript shell) and from the datasheet's answers A6 and A14. Interval widths are the seed 0 bootstrap intervals of the static budget miss in months 5 to 7 (results/ci.csv), shown with the largest seed standard deviation. | The user asked for exact quotes and locations; the API record holds the page's description text verbatim. |
| 6-page | The one-pager is kept at about 540 words counted with numbers and the formula (about 500 words of prose), which fits one page at a normal type size. | "Keep the one-pager to one page." |
| audit 2 | All 13 unsupported claims and the flagged wording from the second claims audit were fixed without changing a number. Bounds stated with "at most" now print enough decimals to be true (0.00142, not 0.0014). PROTOCOL.md keeps the user's verbatim task title "Rolling-origin robustness" because it is a quotation; the RESULTS_POSTHOC.md heading became "Rolling-origin splits". | Banned words apply to this project's prose, not to quoted instructions. |
